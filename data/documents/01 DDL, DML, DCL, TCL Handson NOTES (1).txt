=========================================================
QUESTION 20 - FULL TCL EXAMPLE
=========================================================

SCENARIO:
The bank processes multiple updates and
wants the option to undo some of them.

QUERY:

UPDATE bank_transactions
SET amount=7000
WHERE txn_id=101;

SAVEPOINT SP1;

UPDATE bank_transactions
SET amount=9000
WHERE txn_id=102;

ROLLBACK TO SP1;

COMMIT;

OUTPUT:

Transaction 101 updated and saved.
Transaction 102 restored to previous value.

=========================================================
INTERVIEW TIPS
=========================================================

TRUNCATE
---------
Deletes all rows.
Cannot use WHERE clause.
Faster than DELETE.
Resets storage.

DELETE
-------
Deletes selected rows.
Can use WHERE clause.
Can rollback before commit.

DROP
-----
Deletes table structure and data completely.

COMMIT
-------
Makes changes permanent.

ROLLBACK
---------
Undo changes before COMMIT.

SAVEPOINT
----------
Creates a checkpoint inside a transaction.

GRANT
-------
Gives permissions.

REVOKE
--------
Removes permissions.
