Fundamental Computer Science Algorithms and Data Structures
-----------------------------------------------------------
Algorithms are step-by-step procedures for solving computational problems.
In string processing and information retrieval, matching patterns quickly across large datasets is critical for search engines, bio-informatics, and database indexing.

Binary Search:
Binary search operates on sorted arrays to find target elements in O(log N) steps.
When applied to Suffix Arrays, binary search compares the query pattern string against suffixes in lexicographical order.
By incorporating LCP values, binary search avoids re-checking prefix characters that are already known to match.

Kasai Algorithm Details:
Kasai's algorithm computes the LCP array in linear O(N) time.
It maintains an integer h representing the length of the matching prefix.
For each position i in the original text from 0 to N-1:
- If rank[i] is 0, LCP[0] is set to 0.
- Otherwise, find predecessor suffix j = SA[rank[i] - 1].
- Increment h while text[i + h] equals text[j + h].
- Set LCP[rank[i]] = h.
- Decrement h by 1 if h > 0.

Phrase Search Strategy:
To search for multi-word phrases, the search engine treats the phrase as a sequence of characters or words.
In a suffix array, searching for "suffix array" matches all suffixes that begin with "suffix array".
The range [L, R] in SA contains all occurrences.
Each occurrence index SA[k] is mapped to its source document and highlighted in search results.
